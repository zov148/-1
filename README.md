# NEXA OFFICE V7 — Sky Studio

Сайт продажи и обслуживания оргтехники для XAMPP: PHP 8.0+, PDO, MySQL/MariaDB. Сборка npm не нужна.

## Обновление уже работающего сайта
1. Сделайте резервную копию проекта и базы.
2. Замените файлы в `C:\xampp\htdocs\NEXA_OFFICE\`. Сохраните свой `config.php`, если меняли подключение.
3. Запустите Apache и MySQL; откройте `http://localhost/NEXA_OFFICE/`. Обновите страницу Ctrl+F5.

**Недостающие товары добавляются автоматически при первом открытии.** Не нужно входить администратором или запускать установщик. В каталоге по умолчанию отображаются все 50 подготовленных моделей, по 10 на категорию. Другие существующие товары не удаляются, поэтому в вашей базе итоговое количество может быть больше 50.

Обновление `v6_catalog_50` сопоставляет товары по бренду и модели; использует существующие ID, сохраняет цены и остатки, пользователей и заказы. Обновляет категорию и изображение, один раз делает 50 комплектных моделей видимыми. После успешного обновления ставится отметка в `app_migrations`; повторные открытия не создают дубликатов и не отменяют последующие изменения администратора. Для MySQL параллельные обновления защищены именованной блокировкой; записи выполняются в транзакции. Нужны права на CREATE TABLE/INSERT/UPDATE.

## Новая установка
Скопируйте `NEXA_OFFICE` в `C:\xampp\htdocs\`, запустите Apache/MySQL и откройте `http://localhost/NEXA_OFFICE/install.php`. Нажмите «Создать / обновить базу». Затем откройте `http://localhost/NEXA_OFFICE/`.

Администратор новой учебной базы: `admin@nexa.local` / `admin123`. Параметры БД — в `config.php`; проверяются порты 3306 и 3307. `database.sql` предназначен только для ручной установки пустой учебной базы и содержит DROP TABLE; для обновления существующей базы его импортировать не нужно.

## Понятные действия
- Главная: выбрать технику, обратиться в сервис, получить помощь.
- Каталог: общее количество, категории со счётчиками, поиск, сортировка; до 60 карточек на странице.
- Карточка товара: изображение, описание, гарантия, цена и добавление в корзину.
- Корзина: количество, итоговая сумма и оформление. После входа для заказа пользователь возвращается в корзину.
- Сервис: выбор услуги из карточки и подписанные поля заявки. После входа для заявки пользователь возвращается к сервису.
- Личный кабинет: заказы и сервисные обращения; административная панель доступна администратору.

## Визуальная часть V7
Полная новая тема по предоставленным фото и видео: белый фон, голубые и небесно-синие градиенты, лаймовые кнопки, полупрозрачные панели, объёмное синее кольцо. Контент организован как последовательная презентация: первый экран → витрина реальных товаров → основные действия → категории → карточки преимуществ → модели → сервис → этапы покупки → вопросы → финальный переход в каталог. Тематика сайта и реальные функции сохранены; чужие бренды, отзывы и вымышленные показатели из референсов не копировались.

Анимации: мягкое раскрытие при прокрутке, лёгкое вращение/смещение кольца, плавное выравнивание витрины, плавающие полупрозрачные подписи, подсветка карточек под указателем, раскрытие FAQ и индикатор прокрутки. Скролл остаётся обычным: сайт не перехватывает колесо и не блокирует движение страницы. На телефоне витрина листается свайпом; сложная перспектива отключена. Системная настройка уменьшения движения учитывается.

Все изображения, SVG-иконки и Inter находятся локально; внешних CDN и видеоплеера нет. Кольцо подготовлено отдельно в WebP с прозрачностью и двумя размерами. Файлы исходного видео и фото в проект не включены — они служили референсами.

50 товарных изображений — отдельные фотореалистичные ИИ-иллюстрации вымышленных учебных моделей, не фотографии реальных брендовых устройств. Промпты и происхождение: IMAGE_NOTES.txt. Лицензия Inter: assets/fonts/LICENSE-Inter.txt.
